# Setup — Retraso en Aerolíneas

## Prerequisites

- Python 3.11 or higher (project was built on **Python 3.13.13**)
- `pip` available in your system PATH

---

## 1. Create the virtual environment

Run this from the project root (the folder that contains `notebooks/` and `data/`):

```bash
python -m venv .venv
```

---

## 2. Activate the environment

**Windows (PowerShell)**
```powershell
.venv\Scripts\Activate.ps1
```

**Windows (cmd)**
```cmd
.venv\Scripts\activate.bat
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Your terminal prompt should now show `(.venv)`.

---

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

### What gets installed

| Package | Purpose |
|---|---|
| `pandas` | Data loading, cleaning, and transformation in the notebook |
| `jupyterlab` | Browser-based notebook environment |
| `ipykernel` | Connects the `.venv` Python kernel to JupyterLab |

---

## 4. Register the kernel (first time only)

This makes the `.venv` interpreter visible as a selectable kernel inside JupyterLab:

```bash
python -m ipykernel install --user --name retraso-aerolineas --display-name "Python (retraso-aerolineas)"
```

---

## 5. Launch JupyterLab

```bash
jupyter lab
```

Open `notebooks/01_data_exploration.ipynb` and select the **Python (retraso-aerolineas)** kernel.

---

## Project structure

Only directories that contain files are listed here.

```
Retraso en Aerolíneas/
├── .venv/                        # virtual environment — do NOT commit
├── data/
│   ├── raw/                      # original source files from DOT
│   │   ├── flights.csv
│   │   ├── airlines.csv
│   │   └── airports.csv
│   └── processed/                # cleaned CSVs exported by the notebook
│       ├── flights_clean_all.csv
│       ├── flights_arrived.csv
│       ├── flights_cancelled.csv
│       ├── flights_diverted.csv
│       ├── airlines_clean.csv
│       └── airports_clean.csv
├── notebooks/
│   └── 01_data_exploration.ipynb # exploration, cleaning, and export
├── .gitignore
├── requirements.txt
└── SETUP.md                      # this file
```

### Rules for the team

- **`data/raw/`** — drop source files here as-is; never modify them.
- **`data/processed/`** — generated by the notebook; re-run the notebook to regenerate them. Do not edit manually.
- **`notebooks/`** — one notebook per stage, prefixed with a two-digit number (`01_`, `02_`, …) so they sort in execution order.
- **`.venv/`** — never commit this folder. It is already listed in `.gitignore`.
- Do not create new directories unless they will contain files; empty folders add noise and confuse the structure.
